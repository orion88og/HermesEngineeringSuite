# HES-BP-001 Project Charter

## Purpose
Hermes Engineering Suite (HES) will be a local-first engineering operating system integrating software engineering, CAD, manufacturing, networking, AI, documentation, automation and business management.

## Mission
Build the best self-hosted engineering operating system for engineers, makers, inventors and engineering businesses.

## Scope
HES is intended to become the central engineering workspace for planning, designing, building, documenting and operating technical projects over many years.

## Guiding Values
- Local-first
- API-first
- Modular architecture
- Git is the source of truth
- Documentation is part of the product
- Small, complete increments
