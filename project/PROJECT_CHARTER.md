# 1. Purpose

Hermes Engineering Suite (HES) is a local-first engineering operating system
designed to bring engineering, design, manufacturing, networking,
documentation, artificial intelligence, and business management into a single,
cohesive workspace.

The objective is not to create another chatbot or project manager. The objective
is to create the central engineering workspace from which an engineer can design,
build, document, automate, manufacture, and manage complete projects.

---

# 2. Mission

Build the best self-hosted engineering operating system for engineers, makers,
inventors, product developers, and small engineering businesses.

---

# 3. North Star

Every feature added to HES must answer the following question:

    Does this help an engineer design, build, document, automate,
    or manage real engineering work?

If the answer is no, it does not belong in HES.

---

# 4. Success Criteria

A successful HES platform will:

- Be local-first.
- Support multiple AI providers.
- Organize every engineering project in one place.
- Become the user's primary engineering workspace.
- Remain understandable and maintainable for many years.

---

# 5. Guiding Principles

1. Architecture before features.
2. Documentation is part of the product.
3. Git is the source of truth.
4. Small, complete, working increments.
5. Open standards whenever practical.
6. AI assists engineering; it does not replace engineering.
7. Quality is preferred over speed.

---

# 6. Scope

Included:

- Backend platform
- Frontend dashboard
- Knowledge management
- AI orchestration
- CAD integration
- Manufacturing
- Networking
- Business management
- Automation
- Plugin ecosystem

Not Included:

- Social networking
- Advertising
- Cloud-first lock-in
- Vendor-specific dependencies without abstraction
