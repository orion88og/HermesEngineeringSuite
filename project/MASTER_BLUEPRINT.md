# HERMES ENGINEERING SUITE
# PACKAGE 0 – MASTER BLUEPRINT

Version: 0.1
Status: Living Document

## 1. Mission

Build the best self-hosted engineering operating system for engineers, makers,
inventors, product developers, and small engineering businesses.

HES is intended to become the single workspace from which a user can manage
engineering projects, AI assistants, CAD, manufacturing, networking,
documentation, automation, business operations, and knowledge.

## 2. North Star

Every feature must answer one question:

"Does this help an engineer design, build, document, automate, or manage real projects?"

If not, it does not belong in HES.

## 3. Guiding Principles

- Local-first
- API-first
- AI assists engineers; AI does not replace engineering
- Small, complete, working increments
- Documentation is part of the product
- Git is the source of truth
- Open formats whenever practical
